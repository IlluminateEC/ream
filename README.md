# Ream

Ream is a BEAM language intended to provide a powerful type system built around tuples, atoms, and maps and pattern matching on them.

## Planned Features

### v0.1.0
- Structural typing
- Functions
- Method syntax and resolution
- An LSP
- Imports
- Pattern matching
- Tuples
- Maps
- Atoms
- Strings
- Integers
- Floats
- Closures

### v0.2.0
- Traits
- If statements (maybe)
- Early returns (maybe)
- Bitstring pattern matching and constructing
- A formatter
- A Rust bindings generator
- Access specifiers (maybe)
- Pipeline operator
- String interpolation
- Spreading & Unpacking

### v0.3.0
- Documentation generation
- Macros
